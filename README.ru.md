# Scrawl

[English version](README.md)

Быстрый скриншотер с аннотациями для **GNOME на Wayland**. Нажали клавишу,
выделили область на любом мониторе, нарисовали стрелки, рамки, текст, размыли
личные данные, и результат лежит в буфере обмена и в файле. Без диалога «какой
экран показывать?» при каждом снимке.

> Статус: личный проект в активной разработке, релиза пока нет.
> Пока только Linux (GNOME, Wayland); порт на Windows в планах. Текст интерфейса
> (кнопки, уведомления, подписи) пока только на русском.

## Возможности

- Замороженный экран на всех мониторах появляется примерно через 150 мс после
  хоткея.
- Выделение с пунктирной рамкой: за углы рамку растягивают; инструментом
  «выделение» можно тянуть за любую сторону и перетаскивать область целиком.
- Инструменты: перо, линия, стрелка, рамка, маркер, **размытие**, текст. Восемь
  цветов; колесо мыши или кнопки «−»/«+» меняют толщину, размер текста или силу
  размытия.
- **Подборка «было/стало»:** откладываете снимки, потом склеиваете их рядом с
  подписями «Было»/«Стало» (или «Шаг N») или отправляете отдельными файлами.
- Запоминает прошлую область и возвращает её одной клавишей (`R`).
- Сохраняет PNG в `~/Pictures/Screenshots` и копирует картинку в буфер обмена.
- Отдельное окно настроек (шестерёнка): например, двойной клик внутри выделения
  может копировать его в буфер обмена.

## Требования

- GNOME на Wayland, PipeWire и `xdg-desktop-portal` с регистрацией обычных
  приложений (`org.freedesktop.host.portal.Registry`; разрабатывалось и проверено
  на версии 1.21 и GNOME 50), а также `xdg-desktop-portal-gnome`.
- `wl-clipboard` (`wl-copy`) для буфера обмена, `libnotify` (`notify-send`) для
  уведомлений.

Для сборки: Go (версия из `go.mod`), компилятор C, `pkg-config`, `patch` и
заголовки:

```bash
sudo apt install gcc pkg-config patch libwayland-dev libx11-dev libx11-xcb-dev \
  libxkbcommon-x11-dev libgles2-mesa-dev libegl1-mesa-dev libffi-dev \
  libxcursor-dev libvulkan-dev libpipewire-0.3-dev
```

Нет `sudo`? `scripts/fetch-pipewire-headers.sh` распакует заголовки PipeWire в
`.deps/`, Makefile подхватит их сам.

## Установка

```bash
make install            # в ~/.local (PREFIX=/usr/local для всей системы)
scrawl -setup    # один раз: GNOME спросит про каждый монитор
scrawl -grant-screenshot
scripts/gnome-hotkey.sh # назначает Print на scrawl
```

- `-setup` показывает по одному диалогу GNOME **на монитор**: каждый раз
  выбирайте другой монитор и оставляйте галочку «Запомнить этот выбор». Потом
  диалогов не будет.
- `-grant-screenshot` даёт приложению разрешение, нужное запасному пути захвата
  (см. ниже). Это одна запись в хранилище разрешений portal.
- `-version` печатает версию сборки и выходит (она же в окне настроек).
- `scripts/gnome-hotkey.sh [КЛАВИША] [БИНАРНИК] [--dry-run]` создаёт
  пользовательский ярлык GNOME и не перезаписывает уже занятую комбинацию.

### Обновление с screen-editor

Scrawl это новое название screen-editor. Пока нет файла
`~/.config/scrawl/config.json`, настройки берутся из
`~/.config/screen-editor/config.json` (старый файл не меняется). Выбор
мониторов и разрешение на снимки portal привязывает к идентификатору
приложения, а он сменился, поэтому один раз выполните `scrawl -setup` и
`scrawl -grant-screenshot` и перенаправьте горячую клавишу на `scrawl`
(`scripts/gnome-hotkey.sh`). Прошлая область и подборка начинаются заново.

## Использование

Нажмите хоткей и выделите область мышью. Клавиши:

| Клавиша | Действие |
| --- | --- |
| `Enter` | сохранить в файл и скопировать (меняется в настройках) |
| `Ctrl+C` / `Ctrl+S` | только скопировать / только сохранить |
| `Ctrl+Z` | отменить |
| `Esc` | отмена |
| `R` | вернуть прошлую область |
| `A` / `G` / `D` | в подборку / склеить подборку / отправить подборку файлами |
| колесо мыши | толщина, размер текста или сила размытия текущего инструмента |

Флаги: `-v` печатает замеры времени, `-fresh` игнорирует запомненную область,
`-setup` заново выбирает мониторы, `-settings` открывает окно настроек.

Файлы: картинки в `~/Pictures/Screenshots`; состояние (токены мониторов,
прошлая область, подборка) в `~/.cache/scrawl/`.

## Настройки

Окно настроек открывается шестерёнкой на панели инструментов (она закрывает
оверлей и открывает отдельное окно), командой `scrawl -settings` или
пунктом «Настройки» в меню приложения. Изменения применяются сразу. Настройки лежат в
`~/.config/scrawl/config.json`, файл можно править и руками:

```json
{
  "enter": "copy",
  "dim_percent": 60,
  "tools": { "marker": { "color": "#FDD835" } },
  "glue": { "before": "Before", "after": "After" }
}
```

| Ключ | Значения | Что значит |
| --- | --- | --- |
| `double_click` | `off` (по умолчанию), `copy`, `copy_save` | что делает двойной клик внутри выделения (с инструментом «выделение») |
| `enter` | `copy_save` (по умолчанию), `copy`, `save` | что делает `Enter` |
| `keep_open` | `false` | не закрывать оверлей после копирования и сохранения (выход по `Esc`) |
| `notifications` | `true` | уведомления после снимка; ошибки показываются всегда |
| `remember_region` | `true` | запоминать прошлую область и предлагать её при следующем запуске |
| `include_cursor` | `false` | рисовать курсор мыши в снимке (только при захвате через PipeWire) |
| `save_dir` | каталог, по умолчанию пусто | куда класть файлы; пусто значит `~/Pictures/Screenshots` |
| `file_prefix` | текст, по умолчанию пусто | начало имени файла, дальше дата и время; пусто значит `scrawl` |
| `format` | `png` (по умолчанию), `jpeg` | формат файла; в буфер обмена всегда идёт PNG |
| `jpeg_quality` | 1-100, `90` | качество JPEG |
| `default_tool` | `select` (по умолчанию), `pen`, `line`, `arrow`, `rect`, `marker`, `blur`, `text` | инструмент, который включается после выбора области |
| `tools` | объект по инструментам: `{"arrow": {"color": "#E53935", "width": 6}}` | цвет (`#RRGGBB`) и толщина по умолчанию для каждого инструмента; цвет действует, пока вы не выбрали цвет в панели |
| `palette` | список из 8 цветов `#RRGGBB` | цвета в панели инструментов |
| `marker_opacity` | 5-100, `43` | непрозрачность маркера, % |
| `dim_percent` | 0-100, `86` | затемнение вне области, % |
| `border_width` | 0.5-4, `1` | рамка выделения: толщина линии, px |
| `border_dash` | 1-20, `4.6` | рамка выделения: длина штриха, px |
| `border_gap` | 0-20, `2` | рамка выделения: пауза между штрихами, px |
| `border_color` | `#RRGGBB`, `#FFFFFF` | цвет рамки выделения |
| `handle_radius` | 0-10, `3` | радиус угловых ручек, px; `0` прячет ручки |
| `show_size` | `true` | показывать подпись «ширина × высота» |
| `glue` | объект: `before`, `after`, `step`, `layout`, `background`, `pad`, `label_size` | склейка «было/стало»: подписи (пусто значит «Было», «Стало», «Шаг»), `layout` `side` (по умолчанию) или `stack`, `background` `light` (по умолчанию) или `dark`, `pad` 0-100 (`28`), `label_size` 12-64 (`28`) |

Отсутствующие и неверные значения заменяются значениями по умолчанию, числа вне допустимого диапазона подрезаются. Неизвестные ключи при записи сохраняются.

## Как это работает

Экран снимается через интерфейс ScreenCast `xdg-desktop-portal` клиентом PipeWire
(`internal/pwcapture`). Сохранённый токен восстановления на каждый монитор
убирает диалог. Mutter отдаёт кадры только когда монитор перерисовывается, а над
полноэкранным окном (прямой вывод) в наших замерах не отдал ни одного; если кадр
не пришёл за 250 мс, программа уходит в запасной путь через Screenshot portal
(медленнее, около 0,5–1 с). Оверлеи это
полноэкранные окна [Gio](https://gioui.org), по одному на монитор; Gio
пропатчен (`third_party/gio.patch`), чтобы ставить окно на нужный вывод Wayland.

## Если что-то не работает

- По хоткею ничего не происходит: возможно, завис `xdg-desktop-portal`.
  Перезапустите: `systemctl --user restart xdg-desktop-portal xdg-desktop-portal-gnome`.
- Добавили или заменили монитор: снова запустите `scrawl -setup`.
- Запасной путь пишет, что portal отказал: выполните `scrawl -grant-screenshot`.
