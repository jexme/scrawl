# Справочник по настройкам

[English](SETTINGS.md)

Почти всё настраивается в окне настроек (`scrawl -settings`, кнопка-шестерёнка на
панели или пункт «Настройки» в меню приложений). Изменения сохраняются сразу.
Всё хранится в одном JSON-файле, его можно править и руками:

| Система | Файл |
| --- | --- |
| Linux | `~/.config/scrawl/config.json` (или `$XDG_CONFIG_HOME/scrawl/config.json`) |

Правила файла:

- Любой ключ можно не писать. Пропущенное или неверное значение заменяется
  значением по умолчанию, и одно неверное значение не портит остальные.
- Числа вне допустимого диапазона подрезаются до его границ.
- Неизвестные ключи при записи сохраняются.
- Оверлей читает файл при запуске. Окно настроек применяет изменения к себе сразу,
  оверлей и уведомления берут их со следующего снимка.
- Пока файла нет, Scrawl читает `~/.config/screen-editor/config.json` (прежнее
  название программы) и создаёт новый файл при первом изменении.

Пример:

```json
{
  "enter": "copy",
  "dim_percent": 60,
  "tools": { "marker": { "color": "#FDD835" } },
  "glue": { "before": "До", "after": "После", "layout": "stack" }
}
```

## Действия и поведение

| Ключ | Значения (первое по умолчанию) | Что значит |
| --- | --- | --- |
| `enter` | `copy_save`, `copy`, `save` | что делает `Enter`: копировать и сохранить, только копировать, только сохранить |
| `double_click` | `off`, `copy`, `copy_save` | что делает двойной клик внутри выделения (с любым инструментом, кроме текста) |
| `keep_open` | `false`, `true` | не закрывать оверлей после копирования и сохранения; выход по `Esc` |
| `notifications` | `true`, `false` | уведомления после снимка; ошибки показываются всегда |
| `remember_region` | `true`, `false` | запоминать прошлую область, показывать её при запуске, `R` возвращает её |
| `include_cursor` | `false`, `true` | рисовать курсор мыши в снимке (только обычный захват через PipeWire: не запасной путь через Screenshot portal и не X11) |
| `custom_color` | пусто | свой цвет с радужной кнопки на панели, `#RRGGBB`; программа записывает его сама, когда вы выбираете цвет в оверлее, править не нужно |
| `default_tool` | `select`, `pen`, `line`, `arrow`, `rect`, `marker`, `blur`, `text`, `stamp` | инструмент, который включается, как только выбрана область |
| `keys` | объект | клавиши оверлея, см. ниже |
| `language` | `auto`, `ru`, `en`, `zh`, `es`, `pt`, `ja`, `de`, `fr`, `ko` | язык интерфейса (русский, английский, китайский, испанский, португальский, японский, немецкий, французский, корейский); `auto` берёт язык системы. Региональные записи вроде `zh-CN` и `pt_BR` принимаются |
| `check_updates` | `false`, `true` | спрашивать GitHub Releases о новой версии при запуске окна настроек и значка. Единственный выход программы в сеть; кнопка «Проверить сейчас» работает и без этого |

### Клавиши

`keys` связывает действие с клавишей. Клавиша пишется как `R`, `Enter`, `F5`,
`Ctrl+Z` или `Ctrl+Shift+S` (модификаторы: `Ctrl`, `Shift`, `Alt`; клавиши: буквы,
цифры, `F1`-`F12`, `Enter`, `Escape`, `Space`, `Tab`, `Backspace`, `Delete`,
`Home`, `End`, `PageUp`, `PageDown`, `Up`, `Down`, `Left`, `Right`, `Plus`, `Minus`). Пустое
значение значит «по умолчанию». У двух действий не может быть одной клавиши: если
так вышло, все клавиши возвращаются к умолчаниям.

| Действие | По умолчанию | Что делает |
| --- | --- | --- |
| `confirm` | `Enter` | копировать и/или сохранить (см. `enter`) |
| `cancel` | `Escape` | закрыть оверлей |
| `restore` | `R` | вернуть область прошлого снимка |
| `add` | `A` | добавить снимок в подборку |
| `glue` | `G` | склеить подборку в одну картинку |
| `send` | `D` | сохранить подборку отдельными файлами и положить список файлов в буфер обмена |
| `undo` | `Ctrl+Z` | отменить последнюю аннотацию |
| `copy` | `Ctrl+C` | только копировать |
| `save` | `Ctrl+S` | только сохранить |
| `width_up` | `Plus` | толще линия, крупнее текст или сильнее размытие (как колесо мыши вверх); `Shift` не учитывается, так что работают и `+`, и `=` |
| `width_down` | `Minus` | тоньше линия, мельче текст или слабее размытие |
| `tool_select` | `V` | включить «выделение» (двигать область) |
| `tool_pen` | `P` | включить перо |
| `tool_line` | `L` | включить линию |
| `tool_arrow` | `W` | включить стрелку (arro**w**) |
| `tool_rect` | `B` | включить рамку (**b**ox) |
| `tool_marker` | `M` | включить маркер |
| `tool_blur` | `U` | включить размытие (bl**u**r) |
| `tool_text` | `T` | включить текст |
| `tool_stamp` | `N` | включить штамп с номером (**n**umber): клик ставит кружок со следующим номером, 1, 2, 3 и так далее |

Клавиши инструментов работают, когда область уже выбрана.

## Файлы

| Ключ | Значения (первое по умолчанию) | Что значит |
| --- | --- | --- |
| `save_dir` | пусто | папка для файлов; пусто значит `~/Pictures/Screenshots`; можно `~/Папка` и полный путь |
| `file_prefix` | пусто | начало имени файла, дальше дата и время; пусто значит `scrawl` (например `scrawl-20260131-142501.png`) |
| `format` | `png`, `jpeg` | формат файла; в буфер обмена всегда идёт PNG |
| `jpeg_quality` | `90` (1-100) | качество JPEG |

Два снимка за одну секунду не затирают друг друга: к имени добавляется `-2`, `-3`.

## Инструменты и цвета

| Ключ | Значения (первое по умолчанию) | Что значит |
| --- | --- | --- |
| `palette` | список из 8 цветов `#RRGGBB` | цвета на панели (по умолчанию: красный, оранжевый, жёлтый, зелёный, синий, фиолетовый, белый, чёрный) |
| `tools` | объект по инструментам | цвет и толщина по умолчанию для каждого инструмента: `{"arrow": {"color": "#E53935", "width": 6}}`. Инструменты: `pen`, `line`, `arrow`, `rect`, `marker`, `blur`, `text`, `stamp`. Толщина 1-30; у текста это размер, у размытия сила. Цвет действует, пока вы сами не выбрали цвет на панели |
| `marker_opacity` | `43` (5-100) | непрозрачность маркера, % |

## Вид выделения

| Ключ | Значения (первое по умолчанию) | Что значит |
| --- | --- | --- |
| `dim_percent` | `86` (0-100) | затемнение вне области, % |
| `border_width` | `1` (0.5-4) | толщина линии рамки, px |
| `border_dash` | `4.6` (1-20) | длина штриха, px |
| `border_gap` | `2` (0-20) | пауза между штрихами, px |
| `border_color` | `#FFFFFF` | цвет рамки, `#RRGGBB` |
| `handle_radius` | `3` (0-10) | радиус угловых ручек, px; `0` прячет их |
| `show_size` | `true`, `false` | подпись «ширина × высота» над областью |
| `show_loupe` | `true`, `false` | лупа рядом с курсором, пока выбирают стартовую точку и тянут рамку |

## Склейка «было/стало» (`glue`)

`glue` это объект:

| Ключ | Значения (первое по умолчанию) | Что значит |
| --- | --- | --- |
| `before`, `after` | пусто | подписи для двух картинок; пусто значит слова по умолчанию на языке интерфейса |
| `step` | пусто | слово перед номером, если картинок три и больше («Шаг 1», «Шаг 2», …) |
| `layout` | `side`, `stack` | рядом (одной высоты) или друг под другом (одной ширины) |
| `background` | `light`, `dark` | фон склейки |
| `pad` | `28` (0-100) | отступ от краёв и между картинками, px |
| `label_size` | `28` (12-64) | размер подписи, px |

Подпись не длиннее 30 знаков и без управляющих символов.
