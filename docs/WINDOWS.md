# Windows

Статус: **работает** на Windows 10 и 11: снимок всех мониторов, аннотации, буфер обмена, значок в
области уведомлений и глобальная горячая клавиша. Проверено на двух мониторах с разным разрешением.
Не проверено на мониторах с масштабом выше 100% (см. «Что осталось»).

## Сборка и запуск

Нужны Go (версия из `go.mod`) и Git for Windows (из него берутся `sh` и `patch`).

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-windows.ps1
bin\scrawl.exe            # один снимок
bin\scrawl.exe -tray      # значок в области уведомлений и горячая клавиша
bin\scrawl.exe -settings  # окно настроек
```

`scrawl.exe` собирается как GUI-программа (`-H=windowsgui`): чёрного окна консоли нет. Запущенная из
терминала, она подключается к его консоли, поэтому `-version` и `-v` печатают как обычно.

## Как это устроено

| Что | Где |
|---|---|
| Захват | `internal/wincapture`: `EnumDisplayMonitors`, `BitBlt` (`SRCCOPY\|CAPTUREBLT`) и `GetDIBits` с каждого монитора; процесс объявляется Per-Monitor DPI aware V2 (`cmd/scrawl/dpi_windows.go`) |
| Оверлей на нужном мониторе | патч Gio `third_party/gio.patch` (`app/os_windows.go`): `FullscreenAt` переносит окно на монитор, ставит поверх всех и забирает фокус; окно точно по размеру монитора, без разворачивания (оно остановилось бы на рабочей области) |
| Буфер обмена | `internal/editor/clipboard_windows.go`: формат `PNG` (мессенджеры, браузеры) и `CF_DIB` (Paint, Word); несколько файлов как `CF_HDROP` |
| Один экземпляр | `internal/singleton`: именованный мьютекс `Local\scrawl-<имя>` |
| Значок и горячая клавиша | `internal/tray/tray_windows.go`: `Shell_NotifyIcon` и `RegisterHotKey` в одном процессе; меню «Снимок», «Настройки», «Выход» |
| Комбинация | файл `%AppData%\scrawl\hotkey` в формате GTK (`Print`, `<Control><Alt>a`); меняется в окне настроек, значок подхватывает за пару секунд |
| Автозапуск | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `Scrawl` (`scrawl.exe -tray`) |
| Уведомления об ошибках | окно сообщения (`MessageBox`) |
| Шрифты для китайского, японского и корейского | системные из `%WINDIR%\Fonts` (YaHei, Yu Gothic, Malgun Gothic) |

Горячая клавиша по умолчанию `Print`. Её часто занимает другая программа (Greenshot, «Ножницы»):
тогда значок покажет подсказку, а комбинацию надо выбрать другую в `scrawl -settings`.

## Тесты

Тесты подменяют папки пользователя через `internal/testenv` (на Windows это `%AppData%` и
`%LocalAppData%`, а не `XDG_*`). Тесты `editor` с поддельным `wl-copy` и тест установщика
`install.sh` на Windows пропускаются.

## Выпуск

Тег `vX.Y.Z` (или `vX.Y.Z-rcN`: такой помечается как предварительный) запускает `.github/workflows/release.yml`.
К Linux-пакетам он добавляет в тот же релиз:

- `scrawl-vX.Y.Z-windows-amd64.zip`: `scrawl.exe`, лицензии, README и этот файл;
- `scrawl-vX.Y.Z-windows-amd64.zip.sha256`;
- `scrawl.json`: манифест Scoop с готовым адресом и хэшем.

Архив собирается на `windows-latest` тем же `scripts/build-windows.ps1 -Package`, что и локально, и сопровождается
аттестацией происхождения (`gh attestation verify scrawl-*.zip --repo jexme/scrawl`). В `scrawl.exe` зашиты значок
(`packaging/windows/scrawl.ico`, перегенерируется `go run ./scripts/genicon`), манифест `scrawl.manifest` (Per-Monitor V2,
длинные пути, `asInvoker`) и версия файла из тега.

CI (`ci.yml`, задача `windows`) на каждый пуш собирает программу этим же скриптом, запускает `go vet`, `go test ./...` и
`scrawl.exe -version`.

### Подпись кода

Пока её нет, и это главный источник жалоб: SmartScreen показывает «Windows защитила ваш компьютер», а антивирусы чаще
ругаются на неподписанные программы на Go, которые снимают экран, держат глобальную клавишу и пишут в автозапуск. Варианты:

- **SignPath Foundation**: бесплатно для открытых проектов, нужна заявка; подпись вызывается шагом workflow после сборки;
- **сертификат для открытых проектов** (например, Certum): недорого, на год, ключ хранится на токене или в облаке;
- **Azure Trusted Signing**: доступность зависит от страны и статуса заявителя.

Подпись надо ставить на `scrawl.exe` до упаковки в zip. Репутацию SmartScreen она накапливает не сразу, но с ней
предупреждения и ложные срабатывания исчезают быстрее. До подписи: хэш и аттестация в релизе, на первый релиз отправить файл
как ложное срабатывание в Microsoft Defender, не упаковывать `.exe` упаковщиками.

### winget

Для `winget install` нужен манифест в [winget-pkgs](https://github.com/microsoft/winget-pkgs). Самый простой путь: после
релиза `wingetcreate new https://github.com/jexme/scrawl/releases/download/vX.Y.Z/scrawl-vX.Y.Z-windows-amd64.zip`
(тип `portable`, команда `scrawl`), он сам откроет pull request. Для следующих версий: `wingetcreate update`.

### Что проверить вручную перед релизом

CI не умеет открывать оверлей и нажимать клавиши, поэтому до выпуска:

- масштаб 125–200% и два монитора с разным масштабом: размеры панели, лупа, подпись размера;
- вставка снимка в Telegram, Discord, браузер, Word, Paint, Slack;
- Windows 10 и 11 на чистой машине, где нет ни Go, ни Git;
- клавиша Print на свежей Windows 11 (в Параметрах включено «Использовать кнопку Print Screen для запуска ножниц»);
- курсор уходит с одного монитора на другой: лупа остаётся только там, где курсор;
- автозапуск: включить галочку, выйти из системы, войти, значок появился.

## Что осталось

- **Масштаб выше 100%.** Захват и окна работают в физических пикселях, но размеры панели и подписей на
  мониторах с масштабом 125–200% не смотрели.
- **Уведомления.** Сообщение о сохранении показывается внутри оверлея; тосты Windows (WinRT) не сделаны,
  из системных уведомлений есть только подсказка у значка при занятой комбинации.
- **Игры в эксклюзивном полноэкранном режиме и защищённое видео.** GDI может вернуть чёрный кадр;
  запасной путь через Desktop Duplication (DXGI) или Windows.Graphics.Capture не написан.
- **Курсор мыши в снимке** (`include_cursor`) на Windows не поддержан.
- **Подпись кода и установщик.** Подписи нет (см. «Выпуск»), установщика (MSI) тоже: есть портативный zip и манифест Scoop.
